# Space-weather input

Supply a CSSI-format SpaceWeather-All-v1.2.txt file here, or pass --weather /path/to/file to study.py.
Data are not redistributed in this repository. Public format/source information: https://celestrak.org/SpaceData/SpaceWx-format.php

The example results used a historical input snapshot with SHA-256 `26e68f11875a7be4bed189a19d2ddda978ae8aeb724738b4c4dccb0f3cc80a2b`. A newer data file may change results. The runs replay 2024-04-15 onward; they are not forecasts for a future launch.
